# RANGE 07 · 第一人称战术训练场

低多边形 FPS 网页 Demo。沙地训练地图、四把武器、四名移动人机，支持自由交战和无限重生。地图和模型全部由程序生成，不需要下载模型、字体、贴图或音频，无后端与账号依赖。

## 本地运行

需要 Node.js **22.12+**（推荐 Node.js 22 LTS）和桌面 Chrome / Edge，浏览器需支持 WebGL 2。

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址，点击「开始训练」锁定鼠标。首次点击同时启用音频。Esc 释放鼠标并暂停，点击「继续训练」恢复。

```powershell
npm test            # 核心逻辑测试
npm run typecheck   # TypeScript 检查
npm run build       # 构建到 dist/
npm run preview    # 本地预览生产产物
```

若系统 npm 缓存目录无法写入，可运行 `npm ci --cache .npm-cache`。构建产物可由任意静态 HTTP 服务提供；请通过 HTTP 打开，勿双击 HTML 使用 file 协议。

## 玩法与地图

- 60 × 60 米封闭训练场，包含两座可进入建筑、斜坡高台、集装箱、矮墙、箱体和低顶通道。低顶通道位于训练场西南侧，按住 C 进入。
- 100 点生命值，玩家死亡后 3 秒重生，人机死亡后 4 秒重生。玩家重生恢复生命与弹匣，并获得 2 秒保护。玩家受伤后 4 秒未再受伤开始自动回血，每秒恢复 12 点，回满 100 即止；再次受伤会重置回血等待。
- 步枪：20 伤害、30 发弹匣、每秒 8 发、1.6 秒换弹；18 米内全额伤害，之后线性衰减，60 米外为 55%。手枪：34 伤害、12 发弹匣、每秒最多 3 发、1.2 秒换弹；10 米内全额伤害，40 米外为 50%。
- 狙击枪：60 身体伤害 / 120 爆头伤害（2 倍）、5 发弹匣，每发后需 1.1 秒拉栓，2.4 秒整匣换弹，无距离衰减；腰射散布明显，开镜后收束。霰弹枪：每发 10 颗弹丸、每颗 15 伤害、爆头弹丸 30 伤害、8 发弹匣、0.6 秒射击间隔，0.45 秒逐发装填；8 米内全额伤害，之后衰减，35 米外为 35%。
- 弹匣打空后自动换弹；换弹过程中切换武器会立即打断，已装填的弹药保留。自动换弹与手动 R 换弹使用同一套逻辑。霰弹枪装填过程中开火也会打断装填，保留“原有剩余 + 已装填”的弹药并扣除本次射出的一发。
- 按住右键瞄准：视野收窄、散布降低、第一人称枪模移到中央。狙击枪瞄准时隐藏普通准星、显示圆形镜头准星，并使镜外视野变黑；松开右键恢复腰射。
- 爆头造成 2 倍伤害，并与距离衰减叠加（狙击枪无距离衰减）。命中后准星下方显示伤害、距离与霰弹枪弹丸数，爆头时命中标记变为金色；击杀播报会标注“爆头”与交战距离。
- 掩体阻挡子弹；命中身体默认使用标准伤害，只有头部命中触发爆头倍率。
- 四名人机拥有巡逻、追击、攻击与搜索状态，通过 A* 路径绕障。发现距离 25 米，反应时间 0.8 秒，射击间隔至少 1 秒；命中玩家身体造成 8 伤害，命中头部造成 12 伤害，带瞄准散布。
- 受到人机攻击并实际扣血时，准星周围显示红色受击方向环；方向对应攻击者方位，并随玩家转动视角保持正确。伤害越高，红色楔块越窄、越长、越亮（身体 8 点与爆头 12 点有可见差异）；1.1 秒后淡出，不同方向可同时显示，10° 内合并。
- 暂停后所有战斗、换弹、保护、回血与重生计时冻结，恢复时清除残留输入。

## 技术结构

| 模块 | 职责 |
|---|---|
| `src/main.ts` | 场景初始化、固定时间步长、射线命中、生命周期 |
| `src/world.ts` | 程序地图、Octree 碰撞、导航节点生成、安全出生点 |
| `src/player.ts` / `src/input.ts` | 胶囊体移动、跳跃、蹲姿、键鼠输入与鼠标锁定 |
| `src/combat.ts` / `src/config.ts` | 血量与自动回血、四把武器、散布计算、拉栓、逐发装填、装填打断、自动换弹、爆头倍率、距离衰减与集中参数 |
| `src/bots.ts` / `src/navigation.ts` | 人机状态、可见性检测、移动与 A* |
| `src/weapon-view.ts` / `src/audio.ts` | 四把第一人称枪模、ADS 收枪姿态、后坐力、闪光、合成音效 |
| `src/damage-indicators.ts` | 受击方向换算、伤害尖锐度与指示生命周期 |
| `src/hud.ts` / `src/style.css` | 中文界面、训练简报、地图、血量、四把武器 HUD、瞄准镜头与受击方向指示环 |

Three.js 渲染，Octree + Capsule 处理静态碰撞，120 Hz 固定模拟步长，最大像素比 1.5。导航节点由固定布局采样生成，包含建筑入口与斜坡。Vite、TypeScript、Vitest 用于开发和验证，依赖版本通过 `package-lock.json` 锁定。

开发模式通过 `window.__RANGE__` 提供游戏对象，便于检查角色位置、计时器与导航；生产模式不暴露该入口。

## 当前边界

仅支持桌面键鼠单机体验。人机为简化训练对手，不会跳跃或下蹲；不包含联网、触屏操作、存档、复杂骨骼动画或公共部署。实际帧率取决于设备与浏览器硬件加速情况。
